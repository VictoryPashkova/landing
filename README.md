# DataPeople — лендинг

Одностраничный сайт продукта DataPeople: управление людьми на данных.

- `index.html` — вся страница, без зависимостей и сборки
- `images/` — логотип и фотографии

Шрифты подключаются с Google Fonts, остальное встроено в файл.
Открывается двойным щелчком по `index.html` или отдаётся любым статическим хостингом.
